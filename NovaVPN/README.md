# Nova VPN — راهنمای راه‌اندازی

اپ اندروید (Kotlin + Jetpack Compose) با هسته Xray، سرورهای داخلی، تبلیغ ویدیویی قبل از اتصال و خرید اشتراک از طریق تلگرام.

## ساخت با GitHub Actions (بدون Android Studio)
پوشه `NovaVPN` را در ریشه ریپو و فایل `.github/workflows/main.yml` را هم در ریشه ریپو بگذار. با هر Commit، APK ساخته می‌شود (بخش Artifacts). Workflow خودش `libv2ray.aar` و `geoip.dat` را دانلود می‌کند.

## ۱) باز کردن پروژه (فقط برای Android Studio)
1. Android Studio (نسخه Ladybug یا جدیدتر) را باز کن → **Open** → پوشه `NovaVPN`.
2. صبر کن Gradle Sync تمام شود.

## ۲) اضافه کردن هسته Xray (الزامی)
1. از صفحه Releases پروژه **2dust/AndroidLibXrayLite** فایل `libv2ray.aar` را دانلود کن.
2. آن را داخل `app/libs/` بگذار و Sync کن.
3. فقط فایل `core/XrayCore.kt` با این کتابخانه ارتباط دارد. اگر نسخه‌ات اسم متدها را کمی متفاوت داشت و Build خطا داد، متن خطا را برای من بفرست؛ فقط همان یک فایل تغییر می‌کند.

## ۳) فونت ایران‌سنس
سه فایل `IRANSans-Regular.ttf`، `IRANSans-Medium.ttf` و `IRANSans-Bold.ttf` را در `app/src/main/assets/fonts/` بگذار. اگر نباشند از فونت سیستم استفاده می‌شود.

## ۴) تنظیمات (فایل `Cfg.kt`)
- `CONFIG_URLS`: آدرس raw فایل `servers.json` در GitHub.
- `APP_SECRET`: یک رشته تصادفی بنویس. **دقیقاً همان** را در `tools/servers.source.json` (فیلد `appSecret`) هم بگذار.
- `ADMOB_INTERSTITIAL` و `APPLICATION_ID` داخل `AndroidManifest.xml`: فعلاً آیدی **تست** گوگل است. قبل از انتشار با آیدی واقعی عوض کن.
- نام اپ: `res/values/strings.xml` و `values-fa/strings.xml`.

## ۵) مدیریت سرورها و کدها (بدون آپدیت اپ)
همه چیز در `tools/servers.source.json` است:
- هر سرور: `id`، `name`، `nameFa`، **`cc`** (کد دو حرفی کشور، مثل `CA`؛ پرچم خودکار ساخته می‌شود)، `city`، `premium` (true/false) و `link` (لینک vless/vmess/trojan).
- کشور رایگان یا پولی کردن = عوض کردن `premium`. پرچم عوض کردن = عوض کردن `cc`.
- وقتی حجم یک کانفیگ تمام شد: فقط `link` همان سرور را عوض کن.
- کد فعال‌سازی: داخل آرایه `codes` اضافه کن (با `expires`). برای لغو یک کد، آن را حذف کن.
- `offer`: تخفیف همراه شمارنده معکوس. اگر نخواستی، کل بخش `offer` را حذف کن.

سپس:
```
pip install cryptography
python tools/build_config.py tools/servers.source.json servers.json
```
فایل خروجی `servers.json` را در GitHub آپلود کن (جایگزین فایل قبلی). اپ‌ها هنگام باز شدن و با دکمه «به‌روزرسانی سرورها» آن را می‌گیرند.

**مهم:** فایل `servers.source.json` حاوی لینک‌های واقعی است؛ آن را هرگز در GitHub عمومی نگذار. فقط `servers.json` (رمزنگاری‌شده) آپلود شود.

## ۵.۱) فیلدهای جدید فایل سرورها
- `rev`: خودکار ساخته می‌شود؛ اگر چند آدرس جواب بدهند، جدیدترین فایل انتخاب می‌شود.
- هر سرور: `"bonus": true` (سرور جایزه؛ با دیدن تبلیغ جایزه‌ای باز می‌شود) و `"tag"`: `new` / `busy` / `maintenance`.
- `notice`: پیام قابل‌بستن روی صفحه اصلی (برای نمایش دوباره، `id` را عوض کن).
- `update`: `version` = شماره versionCode اپ. اگر از نسخه نصب‌شده بزرگ‌تر باشد پنجره آپدیت نمایش داده می‌شود؛ با `"force": true` اجباری می‌شود.
- `shareText`: متن دکمه «دعوت دوستان». `bonusMinutes`: مدت جایزه (پیش‌فرض ۶۰ دقیقه).
- چند آدرس برای فایل: در `Cfg.kt` لیست `CONFIG_URLS` (GitHub Pages، jsDelivr، هاست ایرانی و ...).

## ۵.۲) رفتار اتصال
- اتصال به سرور انتخابی؛ اگر پاسخ نداد، خودکار سرور بعدی امتحان می‌شود (حداکثر `MAX_CANDIDATES`).
- اگر هیچ سروری تأیید نشد، به‌طور پیش‌فرض باز هم به اولین سرور وصل می‌شود. برای حالت سخت‌گیرانه `STRICT_PROBE = true` بگذار.
- با تغییر Wi-Fi/داده موبایل، اتصال خودکار دوباره برقرار می‌شود.
- «سایت‌های ایرانی مستقیم» فقط وقتی کار می‌کند که `geoip.dat` در APK باشد (workflow آن را دانلود می‌کند).
- قبل از انتشار: متن «حریم خصوصی» در `strings.xml` فقط یک پیش‌نویس است؛ بخوان و با واقعیت اپ خودت تطبیق بده.

## ۶) فروش اشتراک از تلگرام
دکمه «خرید اشتراک» کاربر را به لینک `telegram` داخل فایل می‌برد. بعد از پرداخت، یک کد برایش بفرست (کد را به `codes` اضافه و فایل را دوباره بساز و آپلود کن). کاربر کد را در اپ وارد می‌کند و سرورهای پولی باز می‌شوند.
محدودیت: بدون بک‌اند، نمی‌شود یک کد را به یک دستگاه محدود کرد. برای هر مشتری کد جدا بساز تا در صورت سوءاستفاده فقط همان را حذف کنی.

## ۷) رفتار تبلیغ
قبل از هر اتصال یک تبلیغ تمام‌صفحه نمایش داده می‌شود (AdMob). اگر تبلیغ در ۴ ثانیه لود نشد، کاربر بدون تبلیغ وصل می‌شود. کاربران پریمیوم تبلیغ نمی‌بینند (`SKIP_ADS_FOR_PREMIUM`).
توجه: گوگل به حساب‌های ایرانی پرداخت نمی‌کند. اگر مشکل پیش آمد، فقط فایل `core/AdManager.kt` را با شبکه تبلیغاتی دیگر عوض می‌کنیم.

## ۸) ساخت APK
`Build → Generate Signed App Bundle / APK`.

## تنظیمات پیشرفته (چرخ‌دنده در پروفایل)
بخش‌های بازشونده مثل v2rayNG: Tunnel، DNS، Core، Mux، Fragment، Observatory، Advanced. همه گزینه‌ها روی کانفیگ Xray و تونل اعمال می‌شوند.
- حالت **Proxy** نیازی به مجوز VPN ندارد؛ فقط پروکسی محلی SOCKS5/HTTP باز می‌شود.
- گزینه‌های Hev TUN، حالت Root و تست همزمان تأخیر در این نسخه نیستند (به کتابخانه بومی یا دسترسی root نیاز دارند).
- ورود با گوگل/ایمیل فعلاً **ساختگی** است (هیچ‌چیز ارسال نمی‌شود) و کادر حجم صفحه اصلی مقدارهای نمونه دارد (`DemoAccount` در `UsageCard.kt`).
